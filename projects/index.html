LLMs for Security

RedSageA Cybersecurity Generalist LLM

ICLR 2026 · First author

An open cybersecurity assistant that runs locally, so security teams do not have to send sensitive data to an external API. Trained on 11.8B tokens of security-focused pretraining data and 266K agentic multi-turn samples, and evaluated on our RedSage-Bench.

Project Paper arXiv Code Models

KaliBenchCybersecurity Tool Use on Kali Linux

NeurIPS 2026 · Co-first author

Can an LLM turn an analyst's request into a command that actually runs? KaliBench tests this with 8,504 verified query-command pairs across 1,642 Kali Linux tools. Its deterministic checks also serve as verifiable rewards, letting an 8B model approach a 685B MoE model.

Sensors 2024 · Co-author

Multimodal Learning

SPARROWPixel-Grounded Video MLLMs

CVPR 2026 · Co-first author

A video MLLM that segments the objects you refer to and keeps tracking the same instance across frames. Tracked target features and joint box and mask tokens reduce drift and identity switches, with gains of up to +8.9 J&F on referring video segmentation.

Project Paper arXiv Code

ReasonCLIP-58MCommonsense Reasoning Supervision for CLIP

ECCV 2026 · Co-author

Continual pretraining that teaches CLIP-style encoders visually grounded commonsense reasoning, using 58M reasoning captions. Used as a drop-in vision encoder in LLaVA-NeXT, it improves results without extra inference cost.

arXiv Code

SAFIREFire and Smoke Understanding in MLLMs

EMNLP 2026 Findings · Co-author

A safety-critical benchmark with 83K captioned images and 193K multiple-choice questions over 10 dimensions, from perception to reasoning. Ten open MLLMs average only 61.9%, which shows how far they are from being reliable in emergency scenarios.

Adversarial Robustness

ACTIVETransferable 3D Physical Camouflage

ICCV 2023 · First author

Adversarial camouflage that hides any 3D vehicle from object detectors. One texture transfers across 15 detectors, other vehicle classes, segmentation models, and the real world.

Project Paper Code

DTADifferentiable Transformation Attack

CVPR 2022 · First author

A neural network that learns how a photo-realistic simulator (CARLA) transforms a texture, which makes white-box camouflage optimization possible there. The resulting camouflage also fooled detectors on a scaled Tesla Model 3.

Project Paper Code

Cityscape-AdverseRobustness Benchmark for Semantic Segmentation

IEEE Access 2025 · First author

Uses diffusion-based image editing to create realistic adverse-condition versions of Cityscapes scenes, and measures how segmentation models hold up.

Paper Code

Adversarial ManholePatch Attack on Depth and Segmentation

WISA 2024 · First author

An adversarial patch disguised as a manhole cover that misleads monocular depth estimation and semantic segmentation in driving scenes.
